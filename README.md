# Student Management System Using MongoDB

## Project Description

This project demonstrates a Student Management System using MongoDB.
It includes database creation, collection creation, insertion of student
records, data retrieval, update, delete, filtering, sorting, limiting,
searching, and counting operations.

## MongoDB Operators Used

| Operator | Meaning |
|---|---|
| `$eq` | Equal to |
| `$gt` | Greater than |
| `$lt` | Less than |
| `$gte` | Greater than or equal to |
| `$lte` | Less than or equal to |
| `$and` | All conditions true |
| `$or` | At least one condition true |
